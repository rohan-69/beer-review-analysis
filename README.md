# 🍺 Beer Review Analysis

This project focuses on analyzing beer reviews to understand user preferences, ratings, and patterns in different types of beers.

## 📌 Problem Statement

Tried to explore what factors influence beer ratings and how users review different beer categories.

## 📊 What I did

* Cleaned and processed raw dataset
* Performed exploratory data analysis (EDA)
* Visualized trends using graphs
* Extracted key insights from user reviews

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook
